The providers page shows a process provider's command-line tool: the vendor's
newest version, whether the entry is held at one, what each connected machine
has installed, and a failed Cloud install with its reason and **Install**. A
process provider's **Test connection** is offered like any other; it runs on
the user's Cloud.

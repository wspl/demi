# Demi Gallery

Live component catalog for `@demicodes/web-ui`.

Style axes remap token values (`surface`, `fg`, `line`, shadow, radius,
density, accent) so you can compare paradigms against the catalog. The product
keeps a single light/dark pair. This package does not ship themes into
runtime.

Start the gallery with this command:

```bash
bun run web:gallery
```

The gallery opens at `http://127.0.0.1:18933`.
